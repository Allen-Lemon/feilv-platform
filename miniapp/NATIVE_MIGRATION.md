# 微信原生架构迁移与检查

## 当前状态

2026-11-13 已将原生代码从 `native/` 提升至 `miniapp` 根目录。微信开发者工具导入 `miniapp`，`project.config.json` 使用 `miniprogramRoot: "./"`。

根目录包含 `app.js/app.json/app.wxss`、`config.js`、`sitemap.json`、`pages/`、`utils/`，不再需要框架编译。

已清理旧 `src/`、旧编译产物文件、uni-app/Vue依赖、旧Vite配置与HTML入口；删除 legacy构建命令。`package.json/package-lock.json` 仅用于零依赖Node检查。`dist` 如被开发工具占用而残留空目录，不是运行入口且已排除上传；关闭旧项目后可删除。

旧代码不再保留在小程序内，历史版本由仓库历史追溯。不要再导入 `miniapp/dist/build/mp-weixin` 或不存在的 `miniapp/native`。

## 页面与接口

| 页面 | 能力 |
| --- | --- |
| 首页 | 三类跑腿服务入口、登录检查 |
| 登录 | 微信 `wx.login`、用户同意、短信备用、验证码冷却 |
| 地址簿 | 增删改、默认地址、向下单页回传选择 |
| 下单 | 取送信息、物品与备注、距离/重量校验、服务端报价 |
| 订单确认 | 费用明细、创建、MOCK模拟支付、已创建订单支付重试 |
| 订单列表 | 分页、下拉刷新、触底加载、错误重试 |
| 订单详情 | 状态、取消/收货、评价、投诉、MOCK补支付 |
| 轨迹 | 实际上报点、地图连线、前台轮询 |
| 我的 | 个人资料、微信无手机号兼容、地址/骑手入口、退出 |
| 骑手入驻 | 短信手机号流程，明确账号切换与演示准入说明 |
| 骑手工作台 | 上下线、抢单、承运分页、取件码、真实定位、送达、信用明细 |
| 服务设置 | 官方HTTPS服务展示，默认禁止改址 |
| 服务与隐私 | 当前数据流及能力限制说明，正式法律文本仍需运营方完善 |

- 微信登录：`POST /api/v1/auth/wechat-login {code, agreed:true}`，返回平台LoginVO。客户端不提交openid/session_key，AppSecret仅存后端。
- 用户订单状态字段为 `status`；骑手专用承运接口为 `statusCode`，不能混用。
- 原生请求层Promise封装 `wx.request`，具有get/post/put/delete，不依赖axios或框架。
- API根地址为 `https://xt.allms.cn`，不要添加/login、/api或5173端口。
- 默认不使用历史开发域名覆盖；版本升级时清理来源不明的旧会话/草稿，不删除服务器业务数据。
- 用户身份、数据归属、状态流转最终以服务端校验为准；前端隐藏按钮不代表安全授权。

## 运行与测试

```bash
npm run build --prefix miniapp
npm run check:wechat --prefix miniapp
npm run check:release --prefix miniapp
```

`build` 运行架构/语法/路径/模板检查及 wx-mock 行为回归，`check:wechat` 编译全部WXML/WXSS。`check:release` 额外检查真实AppID与上传设置；游客AppID会阻止通过。

Node脚本均适配根目录入口，使用内置模块。packOptions排除scripts、文档、包清单及node_modules/dist；目录重新安装依赖或出现Vue源码将被架构检查识别。

测试覆盖请求错误与401、会话切换、微信登录、服务域名锁定、地址选择、订单状态、分页、报价失效、重复提交、支付失败重试、取件码、定位失败及定时器清理。Mock通过不代表微信真机授权、地图渲染、定位权限、支付或审核通过。

## 本轮异常检查与修复

- 地址文字变更时清空旧经纬度，避免继续引用另一地点坐标。
- 未改变的订单草稿保留稳定标识，返回填写页后再进确认页仍复用已创建ID/待核实状态。
- 创建/支付的晚到回调只能写入或清理相同owner+草稿标识的数据，不覆盖下一张订单。
- 已有订单的支付重试先查询状态；已接单/配送中/已完成等已支付状态进入详情，不反复调用支付接口。
- 账号切换前后统一清空页面中已渲染的订单地址、取件码、信用明细等旧数据，即使新请求失败也不残留。
- 异步多步骤操作绑定发起会话；账号改变后后续请求被拒绝，旧响应无法在页面刷新后回填旧账号内容。

本轮已运行：原生架构/语法/注册与事件检查、**33/33 wx-mock行为回归**、微信官方 **13个WXML和14个WXSS文件编译**，均通过。`check:release` 因真实AppID未填写而未通过，未执行上传。

本机旧 `dist/build/mp-weixin` 仅残留被微信开发工具占用的空目录（0个编译文件），其命令行服务端口未开启，未强行终止开发工具；关闭旧项目后可删除该空目录。上传配置明确排除dist，不影响根目录原生运行。

## 明确未实现

真实支付退款、短信网关、OCR/实名审核、照片上传/送达凭证与微信短信既有账号合并仍未完成。新增的资料页支持用户自选昵称及单独授权微信手机号绑定，不支持换号、覆盖他人手机号或自动合并账号；绑定后短信登录会查到同一账号，因此正式上线前必须关闭演示验证码回传并接入真实短信服务，或禁用短信登录。支付页面保持MOCK提示，不展示伪造的上传或定位成功。微信手机号能力资格、隐私指引、资质、正式AppID和后端配套Secret需由运营方配置；离线测试不代表真实授权验收。
